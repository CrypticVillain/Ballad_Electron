# Library data: sources and licenses

The files in this folder (open5e-*.json) were converted by apps/desktop/scripts/library-convert.mjs from Open5e (https://github.com/open5e/open5e-api, data/v2). Open5e's own license follows; each book keeps its own license, listed after it. dyson-maps.json (made by scripts/dyson-maps.mjs) lists Dyson Logos's free commercial maps; the 24 in src/renderer/public/library/maps are his too.
